# Documentation

This project has two parts: the [native conversion toolkit](native-conversion.md), which turns Apple II disks into Mac apps, and [Apple2Forge](apple2forge.md), the bundled app that plays the educational library and runs the toolkit from its Build tab.

## The project

- [Native conversion toolkit](native-conversion.md): tiers (T1, T2-hybrid), stages, the Number Munchers case study and its measured results.
- [Apple2Forge](apple2forge.md): the bundled app, its Library and Build tabs, Settings, and what needs a source checkout.

## Using Apple2Forge

1. [Getting started](getting-started.md): requirements, installing, first launch.
2. [Installing ROMs](installing-roms.md): the Apple II ROM files Apple2Forge needs.
3. [Educational library](library.md): downloading the library and choosing where it lives.
4. [Playing games](playing-games.md): keyboard, joystick mode, display keys.
5. [Disk swapping](disk-swapping.md): titles with more than one disk or side.
6. [Troubleshooting](troubleshooting.md) and [FAQ](faq.md).

## Turning your own disks into apps
